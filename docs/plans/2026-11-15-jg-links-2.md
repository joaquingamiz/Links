# JG Links 2.0 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build a fast, accessible, Web-JG-inspired personal links hub that remains a static GitHub Pages site under `/Links/`.

**Architecture:** Store all managed destinations in one JSON file and render a committed semantic `index.html` with a zero-dependency Node build script. Keep presentation in local CSS and use only minimal progressive-enhancement JavaScript.

**Tech Stack:** HTML5, CSS, JSON, Node.js built-ins, Node test runner, GitHub Pages, Playwright CLI, Lighthouse.
