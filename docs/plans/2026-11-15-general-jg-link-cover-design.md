# General JG Link Cover Design

## Goal

Make JG Links a general personal link cover that uses the supplied JG shield logo, the current public LinkedIn portrait and a clearer set of featured destinations.

## Approved hierarchy

The compact cover remains in English. The supplied shield becomes the primary brand mark in the header and the Official Website feature. The portrait is replaced with the current public LinkedIn profile photo. Featured links use this exact order:

1. Official Website
2. Cyber Age Wars
3. CyberQuiz

The dedicated Learn framing and Blue Team from Zero feature are removed. Remaining destinations are organized as Projects, Content, Training and Connect, with recognizable related icons.

## Constraints

Keep the static generator, relative `/Links/` asset paths, accessibility, responsive behavior, SEO metadata and GitHub Pages configuration. Do not change DNS, Cloudflare, custom domains or Web-JG.
